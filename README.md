# Support for KraftInk

Let members contact your team through private tickets with replies and attachments. Staff can assign requests, add internal notes and follow each ticket through to closure.

Install Support from **Plugins** in the KraftInk admin panel, then open **Extensions → Support** to set up ticket categories.
